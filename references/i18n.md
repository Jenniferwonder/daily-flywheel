# UI language pack (`zh` / `en`)

Read `LANGUAGE` from `local.config.md` at the start of every mode (`zh` | `en`).
Default if missing: `zh`.

**Use this file for all user-facing chat** (questions, tables headers shown to the
user, closers, gate messages). Mode reference files stay English for agent logic;
when they show a Chinese example block, treat it as the `zh` variant and prefer
the matching key below for `en`.

**Do not localize vault schema** — keep section titles and field names from
`conventions.md` stable (`## Actions`, `## Review`, `ToImprove::`, `维度::`,
`目标格::`, `终稿路径`, Tasks `🛫`/`✅`, frontmatter keys). Only the **prose
values** inside those sections follow `LANGUAGE`.

**Draft body language** (article/script): use `draft_language` from
`local.article.config.md` if set; else same as `LANGUAGE`.

Accept user answers in either language regardless of `LANGUAGE`.

## review

### review.no_yesterday_task
- zh: 找不到昨日主任务链接，跳过复盘门禁；可直接 `df plan`。
- en: No yesterday main-task link found — review gate skipped; you may run `df plan`.

### review.q_block
- zh:
  ```
  1. 昨天主任务完成情况：文件里看到的勾选是否属实？实际耗时？（已能从文件读出的只求确认或补差）
  2. 各计数源的「当前后台绝对数」？（按大目标 Baseline / 验收口径里的来源逐项报；没有的账号报 0。用于刷新 Latest Snapshot）
  3. 昨天发出去的内容有互动数字吗？（阅读/点赞/评论/转发/关注等，没有就写「无」）
  4. 一句话自评 + 一条明天能立刻执行的 ToImprove
  5. （仅当发布槽仍空时）补哪些发布链接？或「未发」
  ```
- en:
  ```
  1. Yesterday's main task: are the checkboxes accurate? Actual time spent? (confirm/correct what files already show)
  2. Current absolute counters per source in the objective Baseline / acceptance rules (0 if no account). Used to refresh Latest Snapshot.
  3. Any engagement numbers on what you published? (reads/likes/comments/shares/follows, or "none")
  4. One-line self-review + one ToImprove you can do tomorrow
  5. (Only if publish slots empty) Which URLs to fill, or "not published"
  ```

- en: I'll record engagement numbers without trend analysis — early samples are noise. Trend pass unlocks after 7 days.

### review.opt_prompt
- zh: 触发了焦点优化。下面 1–3 条方向（含 goalDim + goalStep），请选 0/1/多条，或回复「保持」。
- en: Focus optimization triggered. Here are 1–3 directions (with goalDim + goalStep). Pick 0/1/several, or reply "keep".

### comment.scorecard
- zh:
  ```
  | 项 | 检查 |
  |----|------|
  | 选题 | 三维过滤可读；相对已发有增量 |
  | 结构 | 有 Why 且 ≥3 条理由；漏斗完整 |
  | 正文 | 3 秒开场；5–7 行一块；术语有降维；有当天证据 |
  | 标题 | 数字或反差；低行话 |
  | 排版 | 只用 H1–H3；列表好粘贴；流程可视化（ASCII 即可） |
  ```
- en:
  ```
  | Area | Checks |
  |------|--------|
  | Topic | three-way match readable; increment vs prior pubs |
  | Outline | Why section + ≥3 reasons; funnel present |
  | Body | 3-second open; chunks; terms glossed; evidence |

  | Layout | H1–H3 only; lists paste-friendly; processes visualized (ASCII OK) |
  ```
