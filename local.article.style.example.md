# local.article.style (example)

Copy to `local.article.style.md` (gitignored). `df ship` reads **this file**, not long sample essays.

Fill with executable rules distilled from *your* sample posts: opening, evidence, section rhythm, close, bans. Keep it shorter than a full article.

```markdown
# House style (distilled)

## Voice
- First person; concrete numbers before slogans
- Ban empty era-openers

## Open
- Pain / contrast / surprise in the first screen
- Invite a save/like, then start

## Body
- Claim → proof (step, quote, or number) → so-what
- Prefer one recommended path when comparing options

## Close
- Brand line + one ask in comments
- Link the previous piece in the series when this is a sequel
```
