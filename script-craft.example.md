# script-craft (example)

Copy this file to `script-craft.md` in the same directory and fill it in.
`script-craft.md` is gitignored and never committed. Do **not** put a working
copy under `references/` — that folder is for the open skill.

`df ship` reads this file **only** when task `deliverable` is `script`.
Article days must not open it. Do **not** fall back to `article-craft.md`.

Keep it shorter than a full script. Invented placeholders only in this example.

```markdown
# Script craft (local)

## Packaging gate
- Topic stays the day's task artifact (a named article / demo / event)
- Propose 3–5 video titles + 3-second hooks; no new subject
- Title should name the concrete thing (tool / workflow / result), not a slogan

## Outline gate
- Shape: Why (why watch) → 2–4 viewer scenes → chapter list
- Every chapter has a shot-type: talking-head | screen-record-or-animation | on-screen-text
- Confirming the outline confirms how it will be shot
- ≤12 chapters

## Draft
- Spoken lines follow the confirmed chapters
- Repeat the shot-type on each beat
- Details that would bloat the video go to a linked doc, not the mouth
```
